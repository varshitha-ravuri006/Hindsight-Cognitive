# Vishwas

**Reconciliation tools find the mismatch. Vishwas remembers what it turned out to be.**

Vishwas ("trust") is a GST reconciliation workspace for Indian finance teams. It remembers how each vendor
behaves, dimension by dimension, and what each past GSTR-2B mismatch actually turned out to be, so the
accountant knows which mismatches are likely timing differences and which put input tax credit at real risk.
